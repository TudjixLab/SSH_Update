# Дорожная карта Uli Up / Uli UpS

Публичная информация о ходе разработки. Этапы могут корректироваться.

| Этап | Статус |
| --- | --- |
| Концепция продукта | Завершено |
| Проектирование и интеграция | В работе |
| Основные библиотеки формата, протокола и состояния | Первая реализация опубликована в alpha-ветке |
| Запускаемый Rust-агент Uli UpS | Alpha, проверен в Ubuntu WSL |
| Сборочный worker и компоненты Next.js/systemd | Компоненты реализованы и протестированы |
| Полный автоматический deploy/rollback | Не завершён |
| Приёмка Debian и самообновление агента | Впереди |
| Настольное приложение Uli Up и транспорт | В разработке |
| Первый стабильный релиз | Не выпущен |

Точная готовность серверной alpha: [README](services/uli-ups/README.md).
Предварительные исходники не являются готовым производственным установщиком.
