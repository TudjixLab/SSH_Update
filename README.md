# Uli Up / Uli UpS

Uli Up / Uli UpS — платформа TudjixLab для подготовки и установки обновлений
программных проектов.

В этой ветке опубликован **исходный код серверной alpha-версии Uli UpS 0.1.0**.
Работают Linux-агент, локальное управление, проверка/подготовка подписанных пакетов
и отдельные компоненты сборки Next.js. Полный автоматический цикл установки и
отката ещё не подключён. Версия предназначена для разработки и изолированных тестов.

## Uli UpS

- Самостоятельный Rust-процесс, не зависящий от запуска Node.js/Next.js.
- SQLite Store, журнал заданий и ограниченный локальный Unix socket.
- Проверка подписанного .uli4 и подготовка исходного дерева.
- Отдельная рабочая копия для сборки, журнал намерений, ограниченный build-worker.
- Шаблоны systemd и точечного разрешения управления службами.

Инструкции и точные ограничения: [серверный README](services/uli-ups/README.md).

## Сборка на Linux

Нужны Rust1.100.0, C compiler и поддерживаемая Linux-файловая система.
~~~
cargo build -p uli-ups --release --locked
./target/release/uli-ups --version
~~~

Сервер находится в services/uli-ups, общие библиотеки — в crates/uli4,
crates/protocol и crates/state. Они входят в workspace и необходимы для сборки.
Тестовые ключи и файлы в fixtures синтетические и непригодны для production.

Проверки:
~~~
cargo test -p uli-ups --locked
cargo test -p uliup-state --tests --locked
cargo test -p uli4 --tests --locked
cargo clippy -p uli-ups --all-targets --no-deps --locked -- -D warnings
~~~

## Статус

Проверки процесса, Store, подписанного staging, журнала, экспорта файлов и
компонентов Next.js/systemd выполнены в Ubuntu WSL. Запуск на Debian13, полный
автоматический deploy/rollback и самообновление ещё не приняты.
Не запускайте незавершённые механизмы на рабочем сайте.

Uli Up (настольное приложение), SSH/SFTP-интеграция и полный контроллер обновлений
разрабатываются отдельно. Публичная концепция описывает целевой продукт:
[концепция](CONCEPT.md), [дорожная карта](ROADMAP.md).
