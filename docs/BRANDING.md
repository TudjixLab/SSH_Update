# SSH Update — фирменный стиль

## Название

- Публичное релизное название продукта: **SSH Update**.
- Uli Up — прежнее рабочее название; не использовать в новых пользовательских интерфейсах, заголовках, документации и материалах релиза.
- Uli UpS / `uli-ups` — исторические внутренние технические идентификаторы серверного агента. Сохранять до отдельного решения о совместимом переименовании crate, бинарника, systemd unit, конфигурации и путей установки.

## Фирменный знак

Основной знак — фиолетовая спираль с вытянутым хвостом из утверждённого пользовательского логотипа. В приложении она объединена с круговыми стрелками обновления. Основной векторный файл: `assets/ssh-update-icon.svg`.

Требования:
- без текстовой надписи и без названия внутри иконки;
- тёмная графитово-фиолетовая основа и лилово-фиолетовая графика;
- сохранять читаемость на размерах 16–64 px;
- использовать в Windows GUI, установщике, ярлыках, About/Settings и документации;
- если GUI framework не поддерживает SVG, генерировать PNG/ICO из исходного SVG в build pipeline;
- не растягивать и не перекрашивать знак без необходимости.

## Терминология

- Продукт: SSH Update.
- Windows-клиент: SSH Update for Windows.
- Серверный компонент в пользовательских материалах: SSH Update Agent.
- Формат пакета: `.uli4` — не переименовывать.
- Внутренние имена `uli4`, `uliup-protocol`, `uliup-state`, `uli-ups` пока сохраняются ради совместимости.
