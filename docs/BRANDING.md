# SSH Update — фирменный стиль

## Название

- Публичное название продукта: **SSH Update**.
- Uli Up — прежнее рабочее название; не использовать в новых пользовательских интерфейсах и материалах релиза.
- `uli-ups`, `uli4`, `uliup-protocol` и `uliup-state` пока остаются внутренними техническими идентификаторами ради совместимости.

## Официальный фирменный знак

Официальный знак — предоставленная владельцем проекта неоновая фиолетовая иконка синхронизации с шестерёнкой. Её обязательные элементы: тёмная скруглённая плашка, светящаяся фиолетовая рамка, шестерёнка на заднем плане, две круговые стрелки, центральная спираль с длинным хвостом и трёхчастный индикатор внизу.

Основной векторный файл: `assets/ssh-update-icon.svg`. Он должен воспроизводить именно эту композицию. Не заменять знак произвольной спиралью, монограммой или упрощёнными стрелками.

Правила:
- сохранять исходную композицию, пропорции и неоновую фиолетово-лиловую палитру;
- не добавлять текст или название внутрь иконки;
- не удалять шестерёнку, центральную спираль, хвост или нижний индикатор;
- использовать знак в Windows GUI, установщике, ярлыках, About/Settings и документации;
- для форматов ICO/PNG экспортировать исходный знак без изменения геометрии;
- не растягивать и не перекрашивать знак.

## Терминология

- Продукт: SSH Update.
- Windows-клиент: SSH Update for Windows.
- Серверный компонент: SSH Update Agent.
- Формат пакета: `.uli4` — не переименовывать.
